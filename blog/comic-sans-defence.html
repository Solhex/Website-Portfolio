So often somebody writes an article, or script covering how Comic Sans is one of the worst typefaces ever made. I'll admit I've read a lot of them, but, I've never seemed to wholefully agree.

The Case Against It

It's informal. It has irregular letterforms. It turns up on hospital signage and funeral notices, where it really should not. All fair. Its a typeface with a vibe that need matching. And on top of that microsoft holds a leash on hosting it (sorry Unix users).

The Case For It

Those irregular letterforms are the point. Every character has a distinct shape, which is exactly why a lot of readers with dyslexia find it easier going than a tidier face. It also does something most typefaces don't: it tells you immediately that whatever you're reading is not trying to sell you anything.

Percisely the tone I want here. This is a personal page, maybe a bit crude like a hand-written note taped to a wall, but non-the-less mine (and also accessible).

The Real Argument

The complaint is almost never about the typeface. It's about the abundant use of it, and its placement in less than approperate places. A web where every site uses the same three neutral sans-serifs is a web where every site looks like the same company made it, it just gets boring I missed the chaos of the early days.

So here: a starry background, teal text, spinning mascot, Comic Sans. A page I aim to be remembered and an honest to god homage to the early days of the 1.0 internet.
